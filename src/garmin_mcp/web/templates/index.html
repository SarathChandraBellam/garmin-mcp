How it works

Three steps, about two minutes. You need no password and no database, and nobody else holds your key.

1

Create a key

Create a Personal API key in Garmin Connect. You choose how long it lasts and can revoke it at any time.

2

Add the server

Point your MCP client at /mcp. It signs in with OAuth, and you paste your key once on a consent page.

3

Ask away

"How did I sleep this week?" "Compare my resting HR to last month." Each call fetches live from Garmin.

Get your Garmin Personal API key

Garmin offers a self-serve Personal API, so you can read your own health and activity data with a key you create.

  1. Sign in to Garmin Connect on the web with the account that your watch syncs to.
  2. Open Settings → Personal API Key.
  3. Click Create Key, read and accept Garmin's Personal API terms, and choose an expiry: 30, 90, 180 or 365 days.
  4. Copy the key now. Garmin shows it only once. Store it in a password manager.
  5. Connect a client (below). When the browser opens this server's consent page, paste the key and click Allow.

Good to know

  • Treat the key like a password. Anyone who has it can read your Garmin data.
  • To revoke the key, open the same settings page. Every token made from it stops working.
  • When the key expires, create a new one and reconnect your client.
  • Some metrics, such as Training Readiness and Training Status, are not in the Personal API.

Connect your client

Clients that support MCP OAuth find the sign-in by themselves. Older clients can send the key in a header instead.

In Claude, open Settings → Connectors → Add custom connector and enter this URL:

$mcp_url

Claude opens the consent page. Paste your Garmin key there and click Allow.

claude mcp add --transport http garmin $mcp_url

Then run /mcp in Claude Code and choose Authenticate.

Add this to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "garmin": { "url": "$mcp_url" }
  }
}

Add this to .vscode/mcp.json:

{
  "servers": {
    "garmin": { "type": "http", "url": "$mcp_url" }
  }
}

Send your key on every request with X-Garmin-Api-Key (or Authorization: Bearer <key>):

{
  "mcpServers": {
    "garmin": {
      "url": "$mcp_url",
      "headers": { "X-Garmin-Api-Key": "<your key>" }
    }
  }
}

Privacy and security

Stores nothing

There is no database. Your key is encrypted inside the OAuth token that your client holds. The server decrypts it for each request and then discards it.

Standard MCP auth

OAuth 2.1 with PKCE, dynamic client registration and protected-resource metadata, as the MCP authorization spec requires.

Official API only

The server uses Garmin's Personal API. It does not ask for your password and does not scrape data.
